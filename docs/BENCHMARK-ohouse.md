## 1. 3D 인테리어 기능 벤치마크

| 기능 | 오늘의집 | 홈플랜 3D 현황 | 판단 |
|---|---|---|---|
| 도면 불러오기 | 주소 검색(전국 아파트 95%) / 이미지 업로드 자동 구조 인식 / 도면 제작 요청 서비스 | AI 해석·트레이싱·직접 그리기 | 동급 — 추가 불필요 |
| 사이즈 조정 워크플로우 | 동일 제품 없으면 **유사 제품 배치 후 상세에서 W×D×H 개별 조정** | 인스펙터 좌표 입력만 | ★ 채택 — 치수 오버라이드 |
| 단축키 | `1`=2D, `3`=3D, Shift+드래그=그룹화, Ctrl+C/V | R/Delete/Ctrl+Z만 | ★ 채택 — 1/3 전환, Ctrl+C/V |
| 렌더링 설정 | 시점 지정, **카메라 높이 권장 900~1200mm**, 햇빛 강도 0.3~1.0, 해상도 | PNG 스크린샷만 | ★ 채택 — 조명 강도 슬라이더 |
| 접이식 가구 | 소파베드·식탁·빨랫대 "펼침 여부" 토글 | 없음 | 백로그 — `unfolded` 치수 쌍 |
| 배치안 공유 | 베이크 → 읽기전용 공유 링크 | JSON export만 | 백로그 — URL 해시 공유 뷰 |
| 마이페이지 | 즐겨찾기 + "지금 도면에 사용 중인 가구" | 없음 | ★ 채택 — 카드 "배치 N개" 뱃지 |
| 구매 연결 | 제품 → 쇼핑몰 | 출처 ↗ 스펙 링크 | 유사 — 유지 |
| 배치안 비교 | 방 복사로 A/B | 배치안(variants) 썸네일 | 동급 ✓ |
| 파노라마/1인칭 | 파노라마 촬영, 1인칭 뷰 | 워크스루 ✓ | 동급 |

## 2. 표시 속성 — 제품 카드 (쇼핑몰 관찰)

오늘의집 카드 속성: 할인율·최종가 · 평점+리뷰수 · 브랜드 · 배지(무료배송/오늘출발/단독/1+1/쿠폰) · 색상 옵션 미리보기

| 속성 | 판단 |
|---|---|
| 색상 스와철 미리보기 | ★ 채택 — colorways를 카드에 점 표시 |
| "배치 N개" 뱃지 | ★ 채택 — 현재 도면 사용 수 표시 |
| 배지(벽부착/벽걸이/견적필요) | 기존 보유 ✓ |
| 평점·리뷰수·배송·쿠폰 배지 | 제외 — 데이터 없음 + 시뮬레이터 맥락 불일치 |

## 3. UX 인사이트

**채택**
- "유사 제품 + 사이즈 조정" 워크플로우 — 완벽한 제품이 없어도 시뮬레이션 가능
- 초세분화 필터 — 배치 맥락 필터(벽부착만 등)로 확장 여지
- 집들이 필터(주거형태/평수/스타일) → 배치안 이름+썸네일로 부분 구현됨

**지양 (오늘의집이 비판받은 점)**
- 상품 카드 정보 과부하: 인증가·쿠폰·배송 배지 난립 → 탐색 효율 저하
- 우리 카드는 **실측 치수 중심 절제 구조** 유지. 쇼핑 속성 흉내 내지 않기

## 4. 권장 실행 순위

1. 단축키 `1`(2D)/`3`(3D)
2. 카드 색상 스와철 + "배치 N개" 뱃지
3. 인스펙터 치수 오버라이드 (유사 제품 + 실측 조정)
4. 조명 강도 슬라이더
5. 백로그: 접이식 치수 · 공유 링크 · 다중선택 그룹 이동
