# 2D→3D CV 도면 변환 정확도 감사

평가일: 2026-08-27
대상 엔진: `src/engine/planVision.ts`
최종 판정: **자동 완성 용도로는 부적합. 사용자가 보정하는 초안 생성 기능으로만 사용 가능.**

## 1. 시험 범위

총 2,200건을 현재 제품과 동일한 CV 파라미터로 변환했다.

1,000건 전체에서는 이미지→`RawPlan` 변환과 3D 입력에 필요한 유한 벽·방 좌표를 검사했다. GPU로 실제 3D 프레임을 렌더한 것은 대표 성공·실패 사례다. 따라서 이 감사는 주로 **도면 해석 정확도**를 평가하며, 1,000건 각각의 WebGL 렌더 안정성을 보증하지 않는다.

| 코퍼스 | 건수 | 목적 |
|---|---:|---|
| CubiCasa5K 실제 도면 | 1,000 | 다양한 실제 스타일에서 방·벽·문 정확도 평가 |
| 결정론적 합성 도면 | 1,200 | 노이즈·균열·반전·축척의 통제 실험 |

실도면은 [CubiCasa5K 공식 데이터셋](https://zenodo.org/records/2613548)의 세 유형에서 아카이브 순서대로 층화 추출했다.

- `high_quality`: 362건
- `high_quality_architectural`: 362건
- `colorful`: 276건
- 라이선스: CC BY-NC 4.0
- DOI: `10.5281/zenodo.2613548`
- 표본 manifest SHA-256: `5c0aa3221f67d068f15b1be3177f49159acc67fa7b0fc8dd2593278c8c929565`

표본은 무작위 추출이 아니라, 유형별 아카이브 순서 기반의 결정론적 표본이다. CubiCasa5K는 주거 도면 중심이므로 상업·공장·비정형 건물로 일반화할 수 없다.

## 2. 지표 정의

- **변환 성공률**: 유한 좌표를 가진 벽과 방이 각각 1개 이상 생성된 비율. 결과가 정확하다는 뜻은 아니다.
- **방 F1@IoU 0.5**: SVG 정답 방과 예측 방을 128×128 격자로 래스터화하고, IoU가 0.5 이상인 방을 일대일 매칭한 F1.
- **벽 F1**: 정답 벽 폴리곤과 예측 벽 마스크의 픽셀 정밀도·재현율 조화평균.
- **방 개수 정확 일치율**: 예측 방 개수와 정답 실내 공간 개수가 같은 사례 비율.
- **문 개수 일치도**: `min(정답 수, 예측 수) / max(정답 수, 예측 수)`. 위치 매칭이 아니므로 문 검출 정확도의 상한 성격을 가진 보조 지표다.
- **축척 오차**: 실제 mm/px를 아는 합성 도면에서만 평가했다. CubiCasa5K에는 신뢰할 수 있는 물리 치수가 일관되게 제공되지 않는다.

SVG 좌표는 CubiCasa 공식 `House` 로더와 동일하게 원본 PNG 픽셀에 직접 대응시켰다. 제품의 최대 1,600px 리사이즈 비율만 양쪽에 동일하게 적용했다.

합성 결과는 실제 결과보다 훨씬 높다. 합성 도면은 직교·고대비·연속 벽이라는 엔진의 가정을 공유하므로 실제 정확도의 근거로 단독 사용하면 안 된다. 다만 전체 가로 실측 보정이 축척 오차를 유의미하게 줄인다는 통제 근거로 사용할 수 있다.

- 성공 대표 `high_quality/3653`: 정답 방 5개, 예측 방 5개, 방 F1 100%, 벽 F1 72.71%. UI는 벽 16개·방 5개·문 후보 4개를 생성했고 3D 벽·바닥 렌더에 성공했다.
- 실패 대표 `high_quality/1514`: 정답 방 7개지만 예측 벽·방·문이 모두 0개. 얇은 다색 CAD 선이 최소 벽 두께·긴 런 조건을 통과하지 못했다.

## 6. 현재 정확도에 대한 판정

현재 UI의 “변환 후 2D 편집기에서 보정” 안내는 반드시 유지해야 한다. **94.3% 성공률을 94.3% 정확도로 표현하면 안 된다.** 실제로 정답 방 개수가 맞는 비율은 7.7%, 방 공간 F1은 30.68%다.

따라서 현재 기능은 다음 용도로 제한한다.

- 허용: 굵고 고대비인 직교 도면의 초안 생성, 사용자가 모든 벽·방·문과 실측을 검수하는 흐름
- 불허: 무검수 자동 3D 생성, 견적·시공 치수의 근거, 정확도 보증 문구

자동 완성으로 승격하려면 최소한 별도 검증 세트에서 방 F1 75%, 벽 F1 80%, 문 위치 F1 70% 이상을 달성하고 도면 유형별 하한을 둬야 한다.
