# 실도면 10종 구조 변환 벤치마크

평가일: 2026-08-28

## 목적

FOCSA와 한국 33평 두 사례에 맞춘 회귀를 피하기 위해 공개 라이선스 주거 평면도 8종을 고정 추가했다. 이 평가는 정답 폴리곤이 없는 **구조 생성 특성화 벤치마크**다. 벽·방 개수의 정확도나 사용자 과업 성공률을 의미하지 않는다.

## 데이터 구성

- 기존: FOCSA 아파트 1종, 한국 33평 1종
- 추가: Wikimedia Commons 주거 평면도 8종
- 스타일: 현대 CAD, 색상 도면, 흑백 스캔, 다층 도면, 어두운 배경, 사진·본문이 함께 있는 역사 자료
- 출처·저작자·라이선스·SHA-256: `e2e/fixtures/wikimedia-floorplans.json`
- 재수집: `python scripts/fetch-wikimedia-floorplans.py`

Wikimedia 파일은 Public domain, CC0, CC BY-SA 3.0 또는 CC BY-SA 4.0만 허용한다. API 응답 라이선스가 허용 목록과 다르면 다운로드를 중단한다.

## 실패 분석

1. **어두운 배경 Apartment:** 전체 잉크 비율만 사용하는 반전 판단이 검은 배경과 색상 면을 올바르게 분리하지 못했다.
2. **Space Apartment:** 여러 층이 한 이미지에 쌓여 있어 단일 폐곡면 방 추적 가정에 맞지 않았다.

## 판정

10종으로 확대는 완료했지만 제품 품질을 입증하지는 않는다. 현재 게이트는 “지원 스타일에서 구조 생성이 갑자기 사라지지 않는가”만 감시한다. 벽·방 과검출도 성공으로 잡힐 수 있으므로 `80%`를 정확도 수치로 인용하면 안 된다.

다음 알고리즘 우선순위는 다음과 같다.

1. 테두리·배경 표본을 이용한 어두운 도면 반전 판단
2. 다층/복수 도면 입력 감지와 사용자 분할 안내
