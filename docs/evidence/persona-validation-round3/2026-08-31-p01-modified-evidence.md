# P01 — 실제 수정 근거

- 기준점: `25c8128`
- 환경: Chromium 1440×900, 독립 브라우저 저장소
- 입력: 한국 33평, 451×461, 전체 가로 11,800mm
- 결과: 25벽·6방·7문 변환 적용

관찰:

- `바로 3D 보기`와 툴바 `3D 배치`가 검수 전 비활성화됐다.
- 문 1의 2,200mm 폭을 원본 비율과 비교해 900mm로 수정했다.
- 대표 요소에서 같은 `문 1 · 폭 900mm`를 선택하자 주황색 강조가 표시됐다.
- `수정 완료`와 “2,200mm에서 900mm로 수정” 근거를 저장한 뒤 3D에 진입했다.
- 새로고침 후 문 900mm와 완료 근거가 함께 복구됐다.
- 콘솔 오류·경고와 데이터 손실은 0건이다.

판정: M30 수정 경로 통과. SVG 문 선택의 키보드·보조기술 경로는 P2 후보로 분리했다.
