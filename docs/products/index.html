01

The promise

도면을 결과 이미지가 아니라 수정 가능한 공간 모델로 바꾼다.

입력 이미지는 끝점이 아닙니다. 사용자가 축척과 검출 결과를 검토한 뒤 Project에 적용하고, 동일한 상태를 SVG 2D와 Three.js 3D가 함께 읽습니다. 배치·연결·가격·저장도 이 프로젝트를 중심으로 움직입니다.

자동 변환의 자신감보다 수정 가능성과 실패의 가시성을 우선한다.

1 state2D와 3D가 같은 프로젝트 상태를 읽고 수정
mm저장되는 공간·제품 치수의 공통 단위
draftCV 결과는 자동 정답이 아니라 검토 가능한 초안

03

Truth boundaries

구현된 것과 입증되지 않은 것을 같은 문장에 섞지 않습니다.

영역 현재 사실 판정
도면 편집 동일한 mm 프로젝트를 SVG 2D와 R3F 3D가 공유 구현·브라우저 검증
프로젝트 저장 URL 워크스페이스별 IndexedDB, sessionStorage 캐시·폴백, JSON 왕복 로컬 지속성
도면 인식 브라우저 CV 기본, 로컬 CNN/Raster2Seq는 선택적 연구 모드 사용자 보정 필수
외부 AI OpenAI 호환 포트와 오류 매핑은 있으나 자격 증명·쿼터에 의존 조건부
사용자 가치 실사용자 3–5명 관찰 세션은 아직 완료되지 않음 미검증
04

Expert review

다음 개발 항목은 새 기능이 아니라 반복 실패의 증거에서 나와야 합니다.

자동 테스트 범위는 넓지만 사용성의 최종 증거는 아닙니다. 현재 가장 큰 불확실성은 대상 사용자가 축척 검토, 객체 연결, 저장·복구를 힌트 없이 반복해서 완수하는지입니다.

PRIORITY 1

관찰 세션에서 반복 문제를 수집

3–5명의 실제 이사·리모델링 예정 사용자를 대상으로 과업 완료 시간, 힌트 수, 보정 횟수와 중단 지점을 기록합니다.

PRIORITY 2

반복된 문제만 P0–P3로 분류

한 번의 취향 피드백보다 재현되는 데이터 손실·오배치·이해 실패를 먼저 다룹니다.

BOUNDARY

클라우드 동기화는 현재 약속이 아님

IndexedDB는 같은 브라우저의 지속성을 제공하지만 계정·기기 간 동기화는 제공하지 않습니다. 장기 보관에는 JSON 내보내기가 필요합니다.
